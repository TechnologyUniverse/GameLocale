# Дорожная карта Ghost Exile RU для macOS

| Версия | План |
| --- | --- |
| 2.0 | Первое приложение для macOS. GameHub и CrossOver, поиск установки, проверка языков, применение с резервной копией. Перед публикацией пройти полный сценарий на обоих лаунчерах и проверить запуск вне Xcode. |
| 2.1 | Раздельный выбор языка меню и ритуалов, возврат прежних языков. |
| 2.2 | Проверка сборки, языков и русских файлов ритуалов после обновления Steam. |
| 2.3 | Копирование диагностического отчёта без личных путей и данных аккаунта. |
| 2.4 | Дополнительные библиотеки Steam, внешние диски и запоминание выбранной установки. |
| 2.5 | Проверка новой версии приложения через GitHub. |
| 2.6 | Статусы совместимости сборок Steam и проверка формата настроек. |
| 2.7 | История применения и точечное восстановление языка. |
| 2.8 | Клавиатура, VoiceOver и проверка оформления при уменьшенной прозрачности. |
| 2.9 | Стабилизация полного сценария в обоих лаунчерах, включая обновление и откат. |
| 3.0 | Решение по отзывам. Поддержка второй игры, если есть спрос и для неё можно обеспечить безопасный откат. |
