# Диагностика сообщений macOS / Xcode

Проверено на Mac пользователя 5 ноября 2026 года через Xcode.

## Изменения

- Предпрослушивание WAV передано системному `/usr/bin/afplay`. Проверяется доступность файла; ошибки запуска и ненулевой код завершения показываются в интерфейсе. Добавлены остановка и завершение воспроизведения при уходе с панели. Голосовые файлы не изменялись.
- Выбор папки показывается как sheet основного окна вместо блокирующего `runModal`.
- В Ghost Exile всплывающее стеклянное меню выбора папки заменено прямыми кнопками GameHub и CrossOver.
- Глобальное отключение OSLog, подавление stderr приложения и модификация системных классов не применялись.

## Проверка

Сборка и запуск через Xcode, переключение игр, предпрослушивание, открытие и отмена выбора папки в Phasmophobia и Ghost Exile. В итоговом прогоне `AddInstanceForFactory` и предупреждение `_NSGlassEffectWindow makeKeyWindow` не повторились. `fopen failed for data file` в свежем прогоне также не воспроизвелось; причина исходного сообщения не установлена.

## Оставшиеся сообщения

`Unable to obtain a task name port right for pid 412` и шесть строк `Invalid view geometry` воспроизведены также при временной замене всего приложения минимальным SwiftUI-окном с одной обычной кнопкой, без инициализации Sparkle, аудио, карточек и логики игр. PID 412 проверен через ps: это WindowServer.

Минимальная сцена проверки:

```swift
WindowGroup("Проверка системы") {
    Button("Проверка") { }
        .buttonStyle(.plain)
        .padding(40)
        .frame(width: 600, height: 400)
}
```

После проверки временная сцена полностью удалена, основной интерфейс восстановлен. Устранение этих двух сообщений кодом GameLocale не подтверждено. Появление в минимальном тесте не доказывает, что любое сообщение геометрии всегда безвредно; при реальных дефектах интерфейса нужна отдельная диагностика.
